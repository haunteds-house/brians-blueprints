# Supplied electric-furnace tile

`electric-furnace-tile.txt` is the supplied EFurnace Tile, decoded completely into the adjacent JSON file. The generator repeats its two-furnace geometry, changes the belts to the selected Nauvis tier, substitutes fast inserters, and omits its efficiency-module-3 requests. It adds end caps and a shared input manifold.

The longer furnace-book string could not be fully decompressed. It is not used as a build source; its other tiers need the original text-file export before they can be carried over reliably.
